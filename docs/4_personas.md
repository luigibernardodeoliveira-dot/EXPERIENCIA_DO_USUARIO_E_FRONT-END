# Personas e Mapa de Empatia

Com base na pesquisa e nos dados consolidados no Perfil do Usuário, identificamos três arquétipos que guiarão as decisões de design do FEI Viagens. Como os dados mostraram uma divisão clara entre quem organiza e quem apenas acompanha, definimos duas Personas Primárias e uma Persona Secundária (que atua como apoio no planejamento).

---

## Persona Primária 1: Maria Clara (A Líder Organizadora)

<img width="350" height="300" alt="image" src="https://github.com/user-attachments/assets/447f38a1-f0d8-4c94-b2bc-d83a84088ea3" />



| Campo | Descrição |
| :---- | :---- |
| **Idade** | 25 anos |
| **Ocupação** | Estudante universitária e estagiária |
| **Citação** | "Eu amo viajar com meus amigos, mas odeio ser a chata que fica cobrando o dinheiro de todo mundo no final." |
| **Objetivos** | Centralizar as escolhas do roteiro e automatizar a cobrança de quem está devendo, sem gerar estresse ou constrangimento. |
| **Nível de tecnologia** | Alto — usa smartphone o tempo todo, mas está cansada de criar planilhas complexas que ninguém lê. |
| **Frustração principal** | Ficar sobrecarregada com tarefas, tentar alinhar as datas de todos e o constrangimento de cobrar o acerto de contas. |

## Persona Primária 2: Kauan (O Participante Prático)

<img width="350" height="300" alt="image" src="https://github.com/user-attachments/assets/a599ff1e-c298-4229-86f5-bc5f30859e71" />

| Campo | Descrição |
| :---- | :---- |
| **Idade** | 33 anos |
| **Ocupação** | Professor |
| **Citação** | "Eu me perco muito fácil no grupo. Só me passa um resumo com a hora de sair e o valor que tenho que pagar." |
| **Objetivos** | Acompanhar a viagem sem esforço, encontrando facilmente os horários, os locais e a sua parte nas despesas. |
| **Nível de tecnologia** | Médio a alto — usa bastante o celular, mas costuma silenciar grupos com excesso de mensagens. |
| **Frustração principal** | Informações cruciais (como horários e endereços) se perdendo no meio de dezenas de mensagens de bate-papo. |

## Persona Secundária: Samir (O Colaborador Ativo)

<img width="357" height="307" alt="image" src="https://github.com/user-attachments/assets/ca2941a1-84f9-4530-91c1-f05534d3ebbc" />


| Campo | Descrição |
| :---- | :---- |
| **Idade** | 28 anos |
| **Ocupação** | Analista de Sistemas |
| **Citação** | "Eu ajudo a pesquisar os passeios, mas quando metade do grupo quer uma coisa e a outra metade não quer, vira bagunça." |
| **Objetivos** | Ajudar a decidir o roteiro de forma democrática e rápida, apoiando a líder organizadora. |
| **Nível de tecnologia** | Alto — tem muita facilidade com aplicativos e ferramentas colaborativas online. |
| **Frustração principal** | Divergências de preferências no grupo e falta de uma divisão clara de tarefas para o planejamento. |
